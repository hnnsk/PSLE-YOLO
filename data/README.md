# Datasets

This project uses two publicly available infrared ship detection datasets, **NUDT-SIRST-Sea** and **TISD**, for experimental evaluation.

The original datasets are provided by their respective authors. Please download them from the official sources listed below.

## 1. NUDT-SIRST-Sea

NUDT-SIRST-Sea is an infrared tiny ship detection dataset containing diverse maritime scenes, including open-sea, nearshore, and cloud-interference environments.

- **Dataset:** NUDT-SIRST-Sea
- **Official Repository:** [GitHub](https://github.com/TianhaoWu16/Multi-level-TransUNet-for-Space-based-Infrared-Tiny-ship-Detection)
- **Download:** [Baidu Netdisk](https://pan.baidu.com/s/1cDLlkQb8STkjp74Y7YBA2w)
- **Access Code:** `ad7w`

## 2. TISD

TISD (Three-Bands Thermal Infrared Ship Dataset) contains 2,190 thermal infrared images from three spectral bands, covering both daytime and nighttime maritime scenes.

- **Dataset:** TISD
- **Paper:** [TISD: A Three Bands Thermal Infrared Dataset for All Day Ship Detection in Spaceborne Imagery](https://doi.org/10.3390/rs14215297)
- **Download:** [Baidu Netdisk](https://pan.baidu.com/s/1a9_iT-pdaSZ-hkBYU2Qciw?pwd=fgcq)
- **Access Code:** `fgcq`

## 3. Data Preparation

For the experiments in this project, the images are resized to 256 × 256 pixels. Both datasets are divided into training, validation, and testing subsets using a 7:1:2 ratio.

Please refer to the original dataset publications for further details.
